03 / CONCEPTS

How It Works

01

Array-based stack

Stores values in consecutive array positions. A variable called top tracks the last occupied index. This demo uses a fixed capacity of five.

Push: O(1) • Pop: O(1)

02

Linked-list stack

Each node stores a value and a pointer to the next node. The top pointer refers to the newest node, so insertion and removal happen at the head.

Push: O(1) • Pop: O(1)

03

Stack application

An Undo feature stores previous editor states. The most recent state is restored first, which follows the LIFO principle.

Undo: O(1) per saved state (excluding text-copy cost)
